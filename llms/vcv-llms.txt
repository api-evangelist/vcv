# VCV

> VCV is a recruitment-automation platform (video interviews, candidate screening, assessments, chatbot pre-screening) used for high-volume, graduate, and professional hiring. Its VCV Open API v3 is a bearer-token REST API over https://my.vcv.ai (and https://my.vcv.ru) covering vacancies, candidate responses, video interviews, tests, surveys, invites, tags, users, and company webhooks.

VCV was backed by 500 Global. The developer surface is a Swagger UI at developer.vcv.ru serving the multi-file OpenAPI 3.0.1 spec; there is no separate prose developer portal, no published SDKs, and no OAuth — authentication is an HTTP bearer token. Responses use HAL-style envelopes (_embedded, _links, _total_items) with page/limit pagination and filter[...] query parameters. Outbound webhooks can be registered per company for five events: response_created, response_status_changed, response_comment_created, candidate_refused, vacancy_created.
